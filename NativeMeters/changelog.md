# 1.1.0.0

- Added a first-time setup wizard that helps you place your first meter. Run `/ntm setup` to open it again.
- Added horizontal meters, new presets, and a meter builder with a preview.
- Added an option to show your own DPS in the server info bar.
- Added a Lock button next to unlocked meters.
- Added a confirmation before replacing a meter from the clipboard.
